# Изображения бестиария «Мира Холэна»

## Схема v0.11.3
Каталог `index.html#bestiary`: общий SVG-значок типа и название, без загрузки растровых артов.
Полный лист `creature.html?id=<id>`: один квадратный арт 1:1 и характеристики.
Типы в `visual_type`: `ant` (пехота, исполин, погонщик), `infected-ant` (кордицепс), `beetle` (бомбардир), `worm` (норный червь). Это визуальные категории, не игровые правила. Все значки — в `assets/bestiary/types.svg`.

## Подготовка и происхождение
Шесть артов переданы пользователем в ZIP `<id>-assets.zip`, подготовленных с помощью ИИ. Использованы квадратные PNG 1254×1254. Исходники хранить отдельно от сайта; прежние cover 512×512 и portrait 768×1024 не используются.
Для новых существ достаточно одного квадратного оригинала `<id>-original.png`; генерировать можно в обычном чате, именуя архив по точному ID. Для чужих работ сохранять автора, источник и разрешение; случайные изображения из поиска не считать свободными.

## Размер и сжатие
- На сайте: 768×768 WebP, качество 84, method 6, уменьшение Lanczos, без EXIF.
- Шесть артов: **870 408 байт**, примерно 870 КБ; отдельный файл 125–158 КБ.
- Прежние пары cover + portrait: 1 951 944 байта. Экономия около **55%**; относительно PNG-оригиналов (16 749 991 байт) — около **95%**.
- Сжатие с потерями: абсолютную сохранность каждого пикселя не обещаем. Проверять видимое качество при реальном размере отображения; исходники сохранять для повторного экспорта.
- Лист фиксирует размеры 768×768 и соотношение 1:1, без обрезки квадратной композиции.

## Добавление существа
Файл: `assets/bestiary/<id>-art.webp`. В `bestiary-data.js`:
```js
visual_type: 'ant',
images: {
  portrait: 'assets/bestiary/red-infantry-art.webp',
  portrait_alt: 'Красные муравьи-пехотинцы в подземной колонии'
}
```
Историческое поле `portrait` теперь содержит квадратный арт. `images.cover` не требуется.
Проверять совпадение ID, описание для доступности, загрузку листа на телефоне и ПК. Новый тип добавлять в SVG и список допустимых типов каталога. Игровые данные согласовывать отдельно.
