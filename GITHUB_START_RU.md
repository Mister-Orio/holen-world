# Первый запуск через GitHub

1. Войдите на https://github.com/new и создайте **Public** репозиторий `holen-world` (без README и `.gitignore`).
2. Распакуйте архив v0.7.
3. GitHub → новый репозиторий → Add file → Upload files → перетащите содержимое папки `mir_holena_platform_v07` целиком, **не сам ZIP**.
4. Проверьте, что `index.html` находится в корне репозитория (на одном уровне с `app.js`, `room-engine.js`, `room-ui.js`, `styles.css`).
5. Сделайте commit.
6. GitHub → Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save.
7. Подождите публикации и откройте `https://<логин>.github.io/holen-world/`.
8. Откройте три вкладки этого адреса в одном браузере и проверьте демо-комнату по инструкции в README.

**Не публикуйте реальный пароль или секретный ключ Supabase в репозитории.** В браузерном приложении допустим только публичный anon/publishable key вместе с надёжно настроенной RLS. Сервисный `service_role` должен оставаться исключительно на серверной стороне.

**Перед публикацией проверьте книжные файлы** `books/`, особенно мастерскую редакцию «Великий пакт». Всё содержимое публичного репозитория становится доступно посетителям.

GitHub Pages размещает только статические файлы. Для настоящих комнат на нескольких устройствах нужен ещё backend, например Supabase.
