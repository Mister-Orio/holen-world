# Мир Холэна — игровая платформа

Публичный репозиторий проекта «Мир Холэна».

## Состояние

Первая сборка сайта готовится к загрузке: автономный каталог, правила, семь интерактивных отрядных листов и локальный прототип комнаты (ГМ + 2 игрока).

**Локальный прототип — не защищённая онлайн-комната.** Он работает в нескольких вкладках одного браузера и не поддерживает разные устройства.

## Как развернуть

1. Загрузите содержимое архивной сборки сайта в корень репозитория (не сам ZIP).
2. В `Settings → Pages` настройте `Deploy from a branch`, ветку `main` и папку `/(root)`.
3. Убедитесь, что `index.html` находится в корне.

## Перед публикацией

Проверьте папку `books/`: мастерская энциклопедия «Великий пакт» содержит закрытый для игроков лор. Публичный GitHub-репозиторий делает добавленные PDF доступными любому посетителю.

Для настоящих онлайн-комнат потребуются авторизация, серверная проверка прав, база данных и синхронизация.
