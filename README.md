# Мир Холэна — игровая платформа

**«Мир Холэна»** — авторский проект игровой платформы для настольных ролевых приключений, справочников, персонажей и совместных игровых комнат.

**Автор проекта и оригинальных материалов:** [Mister-Orio](https://github.com/Mister-Orio).  
**Официальный репозиторий:** [Mister-Orio/holen-world](https://github.com/Mister-Orio/holen-world).

## Возможности прототипа

- Путешествия Холэна и «Муравьиная революция» — разные игровые паки.
- Каталоги классов и рас, библиотека правил, книги и справочник заклинаний.
- Семь интерактивных листов отрядов «Муравьиной революции».
- Экспериментальная панель ГМа и комната для проверки боевых действий.

## Статус разработки

Проект находится в стадии прототипа. Сейчас комнаты работают **локально в нескольких вкладках одного браузера**. Настоящая игра между разными устройствами, защищённые аккаунты и серверное разграничение прав ещё разрабатываются. Демонстрационная комната **не предназначена для защиты персональных или секретных данных**.
