# Мир Холэна — игровая платформа

**«Мир Холэна»** — авторский проект игровой платформы для настольных ролевых приключений, справочников, персонажей и совместных игровых комнат.

**Текущая версия интерфейса:** онлайн-альфа 0.12.2. [Открыть сайт](https://mister-orio.github.io/holen-world/).

Разделы загружают свои скрипты и стили при первом открытии. На главной — только навигация, загрузчик разделов и авторизация. Каталог D&D хранит короткий индекс; полный лист подгружается из одного небольшого файла с группой до 20 существ. Поиск, фильтры и соседние ссылки используют индекс, без загрузки всех листов. Перестроение данных без изменения правил: `node scripts/split-bestiary.cjs`; проверка согласованности: `node tests/srd-data.cjs`.

**Автор проекта и оригинальных материалов:** [Mister-Orio](https://github.com/Mister-Orio).  
**Официальный репозиторий:** [Mister-Orio/holen-world](https://github.com/Mister-Orio/holen-world).

**Для продолжения разработки в новом чате:** [PROJECT_HANDOFF_RU.md](PROJECT_HANDOFF_RU.md) — актуальная карта кода, Supabase и безопасных изменений. Не заменяет инспекцию текущего состояния.

## Возможности прототипа

- Путешествия Холэна и «Муравьиная революция» — разные игровые паки.
- Каталоги классов и рас, библиотека правил, книги и справочник заклинаний.
- Семь интерактивных листов отрядов «Муравьиной революции».
- Первые настоящие онлайн-комнаты на Supabase: приглашения, состав, выбор персонажей и проверяемые сервером команды ГМа. Обновления приходят при опросе примерно раз в 6 секунд; это ранняя альфа.
- Старая локальная демонстрация доступна отдельно и не обеспечивает серверную безопасность.
- Подключён Supabase Auth: почта, пароль и игровой ник; создание личных заготовок персонажей с доступом только владельца. Для тестов подключён внешний SMTP через Gmail; доставку необходимо продолжать проверять.

## Статус разработки

Проект находится в стадии прототипа. Регистрация с подтверждением почты уже проверена вручную. Реальные онлайн-комнаты реализованы на уровне серверной альфы и ожидают испытания двумя разными пользователями и сетями; полноценные боевые листы, эффекты и Realtime WebSocket ещё не связаны с сервером. Старая локальная демонстрация не предназначена для защиты данных. [Политика конфиденциальности](privacy.html).
