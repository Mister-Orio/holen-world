# МИР ХОЛЭНА — прототип платформы v0.7

Этот архив содержит семь автономных листов муравьиных отрядов, каталог классов/рас, библиотеку правил с PDF, поиск по заклинаниям и **локальную комнату с панелью ГМа**.

## Важно о состоянии разработки

Комната v0.7 — **локальная техническая демонстрация**, а не общедоступная онлайн-комната. Она сохраняет состояние в `localStorage`, а вкладки одного браузера на одном адресе обновляются через `BroadcastChannel` / событие `storage`. Данные **не передаются между устройствами**. Создание любой роли в интерфейсе — демонстрационное и **не является авторизацией**. Не используйте это для публичной игры или защиты закрытых данных.

## Проверка работы комнаты

1. Откройте сайт на GitHub Pages или с локального веб-сервера (не `file://`, так как работа хранилища в таком режиме отличается между браузерами).
2. В разделе «Комнаты» нажмите «Создать комнату» и скопируйте код вида `ANT-XXXXX`.
3. Откройте этот же сайт во **второй вкладке того же браузера** (не в приватном режиме), зайдите в «Комнаты», введите код и выберите «Игрок 1 — Пехота».
4. Откройте третью вкладку таким же способом, выберите «Игрок 2 — Санитары».
5. Вкладка игрока 1 отправляет заявку на атаку. Вкладка ГМа: «Панель ГМа → Принять / Отклонить».
6. ГМ наносит пехоте −1 ОЗ. Игрок 2 отправляет лечение. ГМ подтверждает, и пехота получает до +3 ОЗ, а у санитаров списывается заряд.
7. ГМ нажимает «Следующий ход»; раунд и ход видны в каждой вкладке.

Повторный вход после перезагрузки вкладки восстановит локально выбранную комнату при сохранённом `sessionStorage`; для новых вкладок нужен код.

## Структура

- `index.html` — общие страницы, комнаты и панель ГМа.
- `styles.css` — стили.
- `app.js` — навигация, каталоги, поиск.
- `room-engine.js` — модели комнаты, заявки, урон, лечение, локальные события.
- `room-ui.js` — интерфейс комнаты и панели ГМа.
- `data.js`, `catalog-data.js`, `holen-rules-data.js`, `items-data.js` — данные библиотек.
- `sheets/` — 7 отдельных HTML-листов (состояния пока **не интегрированы** с комнатой).
- `books/` — книги PDF (содержит мастерскую энциклопедию Холэна).
